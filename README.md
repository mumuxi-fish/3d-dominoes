# 🁎 3D 多米诺骨牌

一个明亮清爽的 3D 多米诺搭建与推倒玩具 —— 摆出你的创意,一键推倒,看连锁反应!

## ✨ 特性

- **三模式编辑**:🖐 放置(单击放置、按住拖动画一排)、✋ 移动(直接拖动)、🗑 删除(单击删除、拖动连续清除)
- **直觉视角**:右键拖动旋转、滚轮缩放、中键平移(触屏双指旋转)
- **贴心辅助**:半透明 ghost 预览 + 朝向指示点、网格对齐、7 色马卡龙色板、R 键旋转方向
- **推倒**:点击任意骨牌开始连锁,或 🚀 一键推倒;推倒时带木质碰撞音效
- **不丢进度**:自动保存到浏览器,刷新/重开自动恢复;Ctrl+Z 撤销 / Ctrl+Shift+Z 重做
- **7 种自动模板**:螺旋、蛇形、三角墙、心形、同心圆、回字、交叉 —— 骨牌朝向沿路径,模板可真实连锁
- **存档互通**:保存/读取到浏览器、导出/导入 JSON 文件
- **首次使用引导** + 随时可开的帮助卡片

## 🛠 开发

```bash
npm install     # 安装依赖
npm run dev     # 本地开发
npm run build   # 生产构建(输出到 dist/)
npm run preview # 预览构建产物
```

技术栈:Vite + TypeScript + Three.js + cannon-es(物理引擎),纯前端、无后端依赖。

## 📋 快捷键

| 按键 | 功能 |
| --- | --- |
| `1` / `2` / `3` | 放置 / 移动 / 删除模式 |
| `R` | 旋转放置方向(45°) |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Delete` / `Backspace` | 删除最后放置的一块 |
| `Esc` | 取消进行中的手势 / 退出推倒模式 |
